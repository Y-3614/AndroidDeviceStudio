# Android Device Studio 用户手册

> 一个跑在浏览器里的 Android 设备工具箱。用数据线连上设备，打开网页就能管理文件、敲命令、投屏、抓日志、装应用、控制电源 —— **不需要安装任何客户端**。

## 一、快速上手

1. 用**数据线**把 Android 设备连到电脑。
2. 在设备上开启 **开发者选项 → USB 调试**。
   （如果没看到「开发者选项」：连续点击「设置 → 关于手机 → 版本号」7 次即可解锁。）
3. 用 **Chrome 或 Edge** 打开本站点（必须 `https://` 或 `localhost`）。
4. 左侧「可用设备」下拉框选中你的设备 → 点「**连接**」。
5. 首次连接时浏览器会弹授权框，**手动选中设备**并点确定。
6. 设备上可能弹出「允许 USB 调试吗？」，勾选「一律允许」并确认。

连上后左侧导航的各个页面即可使用。

## 二、使用前提

| 条件 | 说明 |
| --- | --- |
| **浏览器** | 仅支持 Chromium 内核：**Chrome / Edge**。Firefox、Safari **不支持** WebUSB。 |
| **安全上下文** | 页面必须通过 `https://` 或 `localhost` 访问。直接双击本地 HTML 文件（`file://`）**无法使用**。 |
| **设备** | 已开启 USB 调试，且使用**支持数据传输**的线（部分充电线只能供电）。 |
| **授权** | 首次连接需在弹窗中手动选择设备，这是浏览器安全策略，无法跳过。 |

## 三、连不上怎么办

### 最常见原因：设备被本机 adb server 占用

现象：点「连接」后提示 **「设备已被占用」/「访问被拒绝」**。

原因：本机安装的 `adb`（比如 Android Studio 自带的）已经抢占了设备，浏览器拿不到。

**解决办法**：打开本机命令行（CMD / PowerShell / 终端），执行：

```bash
adb kill-server
```

然后回到网页重新点「连接」。

### 其他排查

- 设备上**没有弹出授权框** → 拔插数据线，或在开发者选项里点「撤销 USB 调试授权」后重试。
- 换了根线就好了 → 说明原线只供电不传数据。
- 仍然失败 → 在「说明」页底部点「**运行诊断**」，会逐条执行基础命令并显示真实返回，把结果发出来即可定位。

## 四、各功能详解

### 设备信息
读取设备型号、Android 版本、SDK、CPU 架构（ABI）、Build 类型、以及设备支持的 ADB 能力列表。
适合快速确认「这台机器是什么固件」。

### 文件管理

- **进入目录**：双击文件夹名。
- **上传文件**：点「上传」，可多选。
- **上传文件夹**：点「上传文件夹」，会**保留完整目录结构**传上去。
- **下载**：先勾选条目再点「下载」。**文件夹会自动打包成 zip**。
- **删除**：勾选后点「删除」（不可撤销，会有二次确认）。
- **新建文件夹**：点「新建文件夹」输入名称。
- 列表展示类型图标、名称、权限、大小、修改时间。

> 受保护目录（如 `/data`）需要提权后才能读写，详见第五节。

### 电源菜单

| 按钮 | 作用 |
| --- | --- |
| 重启 | 普通重启 |
| 重启到 Recovery | 进入恢复模式 |
| 重启到 Bootloader | 进入 fastboot / 引导模式 |
| 关机 | 设备关机 |
| 息屏 | 关闭屏幕 |
| 唤醒屏幕 | 点亮屏幕 |
| 锁屏 | 锁定屏幕 |
| 电源菜单 | 长按电源键效果 |

> ⚠️ 重启 / 关机 / 进入 Recovery、Bootloader 都会**断开当前 USB 连接**，这是正常的；设备重启后需要重新点「连接」。

### WiFi ADB

把 USB 调试切换成无线调试，摆脱数据线：

1. **先用数据线连接**，且手机与电脑在同一局域网。
2. 进入本页，点「**开启 TCPIP**」（默认端口 5555）。
3. 点「**读取设备 IP**」拿到地址，形如 `192.168.1.5:5555`。
4. 在**本机命令行**执行：

```bash
adb connect 192.168.1.5:5555
```

连接成功后可拔掉数据线继续使用 `adb`。想切回 USB：

```bash
adb usb
```

> 说明：浏览器出于安全限制**无法直接建立 TCP 连接**，所以第 4 步必须在本机命令行完成。

### 终端

基于 xterm.js 的交互式 shell，可以像在电脑上一样敲 `ls`、`ps`、`cat` 等命令。

- 「**root 会话**」开关：开启后以 `su` 身份打开会话（设备需已 root）。
- 「清屏」「复制输出」便于取走结果。
- 若当前已是 `adb root` 模式（adbd 本身就是 root），无需再开 su。

### 投屏

- 点「开始投屏」看到实时画面（基于抓帧，帧率通常 5–15 fps）。
- 上方一排按键可远程操作设备：返回、主页、多任务、音量、电源、唤醒、息屏。
- 点「开始录制」把画面录成 **WebM** 文件下载。

### 屏幕截图

一键抓取当前屏幕并下载为 PNG，原分辨率保存。
（部分应用禁止截屏，会提示「该应用禁止了截屏」。）

### 日志 Logcat

功能对齐 Android Studio 的 Logcat：

| 功能 | 说明 |
| --- | --- |
| **等级开关** | `V / D / I / W / E / F` 六个按钮独立开关，默认显示 **Debug 及以上**。 |
| **应用识别** | 点「加载应用列表」后选择包名，**只显示该应用的日志**（按 PID 精确过滤）。应用重启后点「刷新 PID」重新匹配。 |
| **关键字 / 标签过滤** | 与等级、应用过滤**叠加生效**（同时满足）。 |
| **保存到本地文件夹** | 点「选择文件夹」指定一个本地目录，日志会**实时写入该文件夹**，**每 20MB 自动分片**，文件名以**开始采集的时间**命名（如 `logcat-20261127-163012.txt`）。 |
| **自动停止** | 可设置采集 1/5/10/30/60 分钟后自动停止。 |
| **清空设备缓冲** | 在设备上执行 `logcat -c`，清掉历史日志。 |
| **导出** | 把当前过滤结果导出为 txt。 |
| **日志大小显示** | 工具栏实时显示**已写入磁盘的日志大小**（KB/MB）与**当前分片序号**。 |

> 未选择文件夹时日志仅缓存于浏览器内存；选择文件夹后不再受浏览器内存限制。命令侧**不做设备端等级过滤**（全量拉取），因此切换等级**无需重新开始采集**。

> **落盘机制说明**：浏览器的文件写入 API 默认把数据先写到临时文件，只有「关闭」时才真正提交到目标文件。本工具改为**每 3 秒自动提交一次**，因此采集开始后**在文件管理器里立刻就能看到文件，并随时间持续增长**，不用等到停止采集。

### 安装 APK

点「选择 APK 文件」→ 自动推送到所选安装路径（默认 `/sdcard`，可切换 `/data/local/tmp`）并安装，显示进度与结果。
失败时会给出中文原因提示（签名冲突、空间不足、版本降级、包损坏、persistent 应用不可更新等）。

## 四·五、TEST 脚本

页面：**TEST 脚本**。把项目里常用的 `.bat` / `.sh` 流程固化成按钮，**所有命令、路径、包名都可以改成你自己项目的值**，点「保存配置」后会存在浏览器里，下次打开还在（「恢复默认」可还原）。

### ① 日志采集与拉取

| 控件 | 说明 |
| --- | --- |
| **后台 logcat 命令** | 默认 `logcat -v time`，在设备后台运行，输出写入 `/sdcard/yx_log/`。可改成任意 logcat 参数。 |
| **开始采集日志 / 停止** | 启动/停止本地记录（设备端后台进程需重启或 kill 才终止）。 |
| **清空设备日志缓冲** | 等价 `adb logcat -c`。 |
| **要拉取到电脑的路径** | 多行输入，每行一个设备目录。默认已按脚本预置：`/data/yx_log`、`/data/sde`、`/data/sdrv_logs`、`/data/kernel_log`、`/data/anr`、`/data/tombstones`、`/sdcard/yaxon`、`/cluster_config`、`/data/yaxon`。 |
| **选择本地文件夹并导出** ⭐ | 选电脑上的一个文件夹，日志**直接写进该目录**（推荐；日志很大时不占浏览器内存）。 |
| **拉取并下载（zip）** | 不想选文件夹时，把每个目录打包成 zip 直接下载。 |
| **清理设备日志目录** | 对「要清理的设备路径」执行 `rm -rf`，随后可选择重启设备。⚠️ **不可撤销，请先核对路径**。 |

> 目录会自动递归打包；受保护目录（如 `/data/anr`）需要 root，工具会自动尝试提升权限后重试。

### ② Monkey 稳定性测试

| 控件 | 说明 |
| --- | --- |
| **被测应用包名** | 每行一个，默认已按脚本填入 yaxon 系列包名。可自由增删。 |
| **Monkey 参数** | 默认含 `--ignore-timeouts --ignore-crashes --pct-touch 40 …`，可整段修改。 |
| **事件间隔 / 事件总数** | 数字微调，分别对应 `--throttle` 与末尾的事件数。 |
| **命令预览** | 实时显示最终执行的完整 monkey 命令，执行前可先核对。 |
| **后台运行 Monkey** | 在设备后台启动，输出写入 `/sdcard/yx_log/`。 |

### ③ 蓝牙 HCI 日志

需要 root。

| 按钮 | 说明 |
| --- | --- |
| **开启 HCI 日志** | 执行 `setprop persist.bluetooth.btsnoopenable true`。**之后需重启蓝牙或设备**才会开始记录。 |
| **导出 HCI 日志** | 拉取 `/data/misc/bluetooth/logs` 并下载。 |
| **导出到本地文件夹** | 同上，但直接写入你选的本地文件夹。 |
| **删除 HCI 日志** | 清空 `/data/misc/bluetooth/logs`。 |

### ④ CPU / 内存占用监控

| 控件 | 说明 |
| --- | --- |
| **采样间隔（秒）** | 默认 10 秒。 |
| **开始 / 停止监控** | 周期执行 `dumpsys cpuinfo` 与 `dumpsys meminfo`。 |
| **趋势条** | CPU% 与内存% 随时间变化的柱状趋势（保留最近 60 次采样）。 |
| **原始采样** | 下方显示最近一次的原始输出。 |

> 注意：这是**实时采样**，用于快速观察；若要长时间记录，可用你原来的 `shell_cmd.sh` 方式在设备端循环落盘。

### ⑤ 应用管理

| 控件 | 说明 |
| --- | --- |
| **包含系统应用** | 开 = 列出全部应用；关 = 仅第三方应用。 |
| **列出所有应用包名** | 加载应用列表（含当前 PID）。 |
| **搜索框** | 按包名过滤，避免长列表难找。 |
| **启动应用** | 拉起所选应用。 |
| **强制停止** | `am force-stop` 结束所选应用；被停止的应用再点「启动」即可拉起。 |
| **启动前先强制停止** | 勾选后，「启动」会先 force-stop 再拉起，确保**冷启动**。 |

### ⑥ 安装 APK 的安装路径

「安装 APK」页新增**安装路径**下拉：

- **SD 卡（/sdcard）** —— 默认，兼容性最好；
- **/data/local/tmp** —— 若 SD 卡推送失败或提示权限问题，可切到这里。

## 四·六、ADB 命令大全

页面：**命令大全**。

这里收录了 **100 条真实可用的 ADB 命令**，按用途分成 13 类，方便随时查阅和直接用。

### 分类与条数

| 分类 | 条数 | 分类 | 条数 |
| --- | --- | --- | --- |

| 设备信息 | 8 | 输入与界面 | 8 |
| 应用管理 | 9 | 电源与重启 | 6 |
| 安装与卸载 | 7 | 网络与端口 | 8 |
| 启动与停止 | 6 | 屏幕与录制 | 6 |
| 文件操作 | 9 | 系统与权限 | 8 |

### 怎么用

1. **搜索**：顶部搜索框按命令内容、说明或分类过滤；分类下拉可只看某一类。
2. **复制**：每条右侧的 📋 按钮把命令复制到剪贴板，粘到本机终端即可用。
3. **执行**：连接设备后，点 ▶ 按钮会**直接在设备上运行**该命令，并在下方显示真实输出
   （会自动去掉 `adb` / `adb shell` 前缀，只把设备侧命令发给设备）。

### 内置命令 vs 自定义命令

- **内置命令**（带 🔒 标志）：**不可删除、不可修改**，保证基础命令集始终可靠。
- **自定义命令**：点顶部「新增命令」，填分类、命令、说明即可。**自己创建的**命令会显示
  「修改」「删除」按钮；**他人创建的**命令显示「他人共享」，只读。

### 跨用户共享（重点）

- 新增的自定义命令会保存到**云端**，**所有打开这个网站的人都能看到**。
- 页面顶部会显示云端状态：
  - 「已连接云端，自定义命令对所有访客共享」 → 一切正常；
  - 「云端暂不可用，新增命令仅保存在本机浏览器（不共享）」 → 网络异常，
    **此时新增的命令不会共享**；网络恢复后点「刷新云端」重新同步即可。
- 「导出 JSON」可把当前命令集导出为文件，方便分享给不能访问云端的人（对方用「导入」还原）。

> ⚠️ 因为要「所有访客可见」，自定义命令是**公开共享**的，请不要在其中填写密码、密钥等敏感信息。

## 五、提权与挂载

页面：**权限与挂载**。

连接后系统会自动**三级探测**，按成功率依次尝试：

| 顺序 | 方式 | 说明 |
| --- | --- | --- |
| ① | `adb root` | **仅 userdebug / eng 版固件可用**。零售机的 user 版会拒绝，提示 `cannot run as root in production builds`。成功后 adbd 重启、连接断开，页面会自动重连。 |
| ② | `su` | 设备已装 `su`（通常来自 Magisk / SuperSU）时可用，手机端可能弹授权框。 |
| ③ | 普通权限 | 以上都不可用时的降级方案，只能访问 `/sdcard` 等公共目录。 |

### adb remount（把系统分区改成可写）

```
adb root  →  adb remount  →  可写 /system、/vendor
```

**Android 10+（动态分区）** 需要多两步：

```
禁用 verity  →  重启设备  →  adb root  →  adb remount
```

界面上的 `remount` / `disable-verity` 按钮带**依赖联锁**：没 root 成功时自动置灰并提示原因。

### 提权模式下的文件操作

- **`adb root` 模式**：adbd 本身就是 root，直接用原生 sync，**速度快**。
- **`su` 模式**：改走 shell 通道（读取用 base64、写入用 `cat >`、删除用 `rm -rf`），可访问 `/data`、`/system` 等。

## 六、常见问题 FAQ

**Q：为什么「连接」按钮点了没反应？**
A：先看第二节的四个前提。最常见是没用 Chrome/Edge，或页面不是 HTTPS/localhost。

**Q：提示「设备已被占用」怎么办？**
A：在本机命令行执行 `adb kill-server`，然后重新点「连接」。

**Q：为什么 `adb root` 提示不可用？**
A：你的设备是 user 版（量产零售机）固件，adbd 被编译为不可提权。工程样机（userdebug/eng）才能用。可改用 `su` 方案（需设备已 root）。

**Q：`adb root` 之后页面显示断开？**
A：正常现象 —— root 会让 adbd 重启、USB 断开。新版本会自动重连并重新探测权限。

**Q：日志里什么都看不到？**
A：① 确认已点「开始」；② 确认日志等级按钮至少有一个是点亮状态；③ 若选了应用过滤，确认该应用确实在运行（可点「刷新 PID」）。

**Q：日志能保存多久 / 多大？**
A：选择本地文件夹后不限大小，每 20MB 分一个文件，可长时间采集；也可设置自动停止时间。

**Q：投屏帧率低？**
A：当前采用抓帧方案，帧率取决于设备抓帧速度（通常 5–15 fps），未接入 scrcpy 高帧率模式。

**Q：Firefox 能用吗？**
A：不能。Firefox 不支持 WebUSB，请改用 Chrome 或 Edge。

## 七、原理与限制

- **技术路线**：纯前端，通过 **WebUSB** 直连设备并实现 ADB 协议（`@yume-chan/adb`），
  全程不经过任何服务器，设备数据只在你的浏览器与设备之间流动。
- **浏览器安全限制**：
  - 必须 HTTPS / localhost；
  - 必须 Chromium 内核；
  - 首次连接必须用户手动授权；
  - 浏览器无法直接建立 TCP 连接（故 WiFi ADB 需在本机命令行完成最后一步）。
- **投屏**采用 framebuffer 轮询，未接入 scrcpy 高帧率方案。
- **提权**依赖设备端：`adb root` 取决于固件编译属性，`su` 取决于设备是否已 root。
  网页端**无法**把未 root 的设备变成 root。
